# Шаблоны запросов для «Сэм про Опционы» / Active Trading Room

## Instagram-карусель из поста

```text
Сделай Instagram-карусель для «Сэм про Опционы» на основе поста:
[ССЫЛКА НА TELEGRAM-ПОСТ]

Цель: [экспертность / прогрев / вовлечение / CTA].
Слайдов: [5–7, если не укажу, выбери сам].
Аудитория: [новички / знакомые с опционами / смешанная].
CTA: [кодовое слово / комментарий / ссылка / без CTA].

Работай по скиллу atr-options-carousel:
- сначала извлеки факты из поста;
- предложи живой, грамотный русский текст и структуру слайдов;
- покажи структуру на согласование;
- затем сгенерируй финальные PNG через GPT Image 2;
- предметный editorial-стиль Active Trading Room: dark navy, кремовая бумага, глубокий зелёный, латунные детали, мягкий свет;
- каждый слайд как отдельная физическая сцена, без неона, UI, фальшивых биржевых данных и псевдотекста;
- выделяй глубоким зелёным 1–2 ключевых смысловых блока на карточке;
- соблюдай Instagram safe zones, ничего важного не обрезай;
- перед отправкой проверь каждую карточку на текст, контраст и обрезание.
```

## Instagram-карусель из готового текста

```text
Сделай Instagram-карусель для «Сэм про Опционы».

Исходный текст:
[ВСТАВЬ ТЕКСТ]

Цель: [цель].
Слайдов: [количество].
Аудитория: [аудитория].
CTA: [CTA].

Используй скилл atr-options-carousel. Сначала подготовь и покажи финальные тексты, роли и визуальные сцены всех слайдов. После моего «да» сгенерируй всю серию свежими PNG с нуля через GPT Image 2 и проведи QA.
```

## Одна Story из поста

```text
Сделай одну Instagram Story 9:16 для «Сэм про Опционы» на основе поста:
[ССЫЛКА ИЛИ ТЕКСТ]

Задача Story: [зацепить / объяснить один тезис / привести к посту / CTA].
CTA: [текст или ссылка].
Нужна зона под link sticker: [да / нет].

Используй скилл atr-options-carousel. Возьми одну сильную мысль, не перегружай текстом. Сделай цельный PNG через GPT Image 2 в предметной стилистике ATR. Оставь безопасные зоны Instagram Stories: не ставь важный текст сверху и внизу, а при link sticker оставь чистую нижнюю треть. Проверь читаемость и обрезание перед отправкой.
```

## Серия Stories из поста

```text
Сделай серию из [3–5] Instagram Stories 9:16 для «Сэм про Опционы» на основе поста:
[ССЫЛКА ИЛИ ТЕКСТ]

Цель: [прогрев / объяснение / вовлечение / привести к посту / CTA].
Финальный CTA: [кодовое слово / link sticker / комментарий / написать в Директ].

Используй скилл atr-options-carousel. Сначала предложи цепочку Story: хук → ситуация → объяснение → действие → CTA. Затем после согласования сгенерируй свежие цельные PNG через GPT Image 2. Сохрани общий visual DNA ATR, но у каждой Story должна быть своя предметная сцена. Не размещай значимый текст в blind zones Stories и оставь нижнюю треть свободной, если будет link sticker.
```
