# ATR Options Carousel

Публичный skill для Hermes Agent, который превращает Telegram-пост или готовый текст в Instagram-карусель или серию Stories для проекта **Active Trading Room / «Сэм про Опционы»**.

## Что умеет

- извлекает факты из исходного поста, не придумывая торговые claims;
- строит понятную драматургию: хук → ситуация → механизм → вывод → CTA;
- генерирует финальные PNG через GPT Image 2;
- держит единую визуальную систему: dark navy, кремовая бумага, глубокий ATR-зелёный, латунные детали, мягкий предметный свет;
- соблюдает Instagram safe zones для карусели и Stories;
- проверяет русский текст, контраст, псевдотекст, safe zones и визуальные артефакты;
- не строит серии через цепочку image-to-image правок, чтобы не деградировали бумага, шрифты и композиция.

## Установка

Скопируйте `SKILL.md` в каталог навыков Hermes, сохранив структуру `references/`.

## Быстрый запрос

```text
Сделай Instagram-карусель для «Сэм про Опционы» на основе поста:
https://t.me/activetradingroom/1502

Цель: экспертность.
Слайдов: 6.
CTA: кодовое слово «БАЗА».

Используй atr-options-carousel. Сначала покажи структуру и тексты, затем после моего «да» сгенерируй финальные PNG и проверь safe zones.
```

Полные шаблоны: [`references/request-templates.md`](references/request-templates.md).

## Визуальная ДНК

Один слайд — одна реалистичная предметная сцена рабочего стола трейдера: матовый navy, кремовая бумага, сдержанный зелёный акцент, латунь, мягкий направленный свет. Без неона, фейковых терминалов, монет, ракет, псевдотекста и выдуманных рыночных данных.

`CALL` и `PUT` допустимы как профессиональные термины. Цветом выделяются только 1–2 смысловых якоря на слайде.
